Easy Editing

  1. Logo: a built-in API is included, so leave it blank and the logo will load automatically.

  2. Description: you can copy the description from the site itself. In a desktop browser, press F12, search for “desc” in the “Elements” panel, and the first result is usually the one you need.

  3. QR code: you can enter an API link, for example: https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=https://netcut.cn/

    It loads a bit slowly, though — using a local image is faster.

  4. FontAwesome icons: https://origin.fontawesome.com/v6/search
