To add a new site or change site information, just maintain:

data/webstack.yml

Then run:

python scripts/generate-sites.py
hugo

This will automatically:

- Generate detail pages
- Generate English slugs automatically
- Update data/site-slugs.yml
- Link the homepage to the detail pages automatically

Example — add:

- title: OpenAI
  url: https://openai.com/
  description: An AI research and product platform

You will automatically get:

content.en/sites/openai.md

Homepage link:

/sites/openai/

Update the blog

python3 scripts/generate-sites.py

git add .
git commit -m "add tuiwen-novelpop.dev"
git push -u origin main

Latest update

python scripts/generate-sites.py

git pull --rebase

git add .
git commit -m "Update website"

git push

Note: the site is now English-only. There are no Chinese or Russian
versions — do not add content.zh, content.ru, i18n/zh.toml, or i18n/ru.toml.
